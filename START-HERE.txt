PRIVATE EDITING STUDIO — ONE-TIME CLOUD SETUP REQUIRED
/studio.html is an editing interface, but the public website is functional WITHOUT it.
The private editor is NOT active until you set up Supabase.
Steps (best done on a desktop for the first time):
1. Create your own project at https://supabase.com and keep the login secure.
2. Under Authentication > Users, add ONLY your own login. Prefer disabling public sign-ups.
3. Run setup.sql in Supabase SQL Editor.
4. In Supabase Authentication > Users copy YOUR user's UUID.
5. Run this SQL statement, replacing the example UUID with your actual UUID:
     insert into public.site_admins(user_id) values ('YOUR-UUID-HERE');
6. In Supabase > Project Settings > API, copy Project URL and PUBLIC anon/publishable key.
7. Edit config.js with only those two public values. NEVER put a service_role or secret key in public files.
8. Redeploy the updated ZIP to the SAME Netlify project.
9. Visit /studio.html, sign in as owner, and tap Activate my film library ONCE.
10. From then on, project data, images, YouTube URLs and your public contact email
    can be saved in your owner-only studio without reuploading the website files.
    Public visitors can never use the editing permissions because of Supabase RLS policies.
